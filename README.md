在瀏覽器上直接連 PTT 的網頁版終端機。以 PTT 官方網頁版 [term.ptt.cc](https://term.ptt.cc) 的原始碼（[robertabcd/PttChrome](https://github.com/robertabcd/PttChrome)）為基底，加上一系列閱讀與操作的增強功能。

👉 **立即使用：<https://abccbaandy.github.io/PttChrome/>**（連不上請看下方的「連線修復指南」）

## ✨ 功能特色

> 相較原版新增的功能，多數可在「偏好設定」（畫面按右鍵）開關。

### 📖 閱讀文章

- **好讀模式** — 文章自動翻頁、整篇連續捲動，像看網頁一樣；長文按 `End` 直接從文末讀起，`F8` 切回原生模式。
- **Ctrl+F 搜全文** — 好讀模式下直接用瀏覽器內建的尋找功能搜整篇文章。
- **推文篩選** — 長按（桌機右鍵）推文選「只看這個人」「只看原 PO」或「只看推文／噓文」，其他推文收成一條「略過 N 則」，上方切換鈕帶各自則數、可直接換篩選。
- **新推文標記** — 重開讀過的文章時，上次讀完之後的新推文前面有一條灰線，可一鍵跳過去；文章列表上讀過的文章會標出推文數多了幾（+N），點它就開文並直接跳到新推文。
- **推文樓層編號** — 推文標上樓層號，跨頁也連續。
- **同作者連續推文合併** — 同一人連續的推文合成一塊，去掉一再重複的帳號與時間。
- **推文區塊行距** — 推文之間拉開距離，同作者合併塊內部較緊，一眼分出誰說了什麼。
- **高亮原 PO／自己／點選推文者** — 原 PO 與自己的推文帳號自動上色，提到你的推文左緣有綠線；點推文列可高亮該帳號的所有推文。
- **讀完接著讀下一篇** — 好讀文章讀到最後，推文下面出現列表上下一篇（另列同主題的上一篇／下一篇）的標題卡，點一下、在文末停住再往下捲（手機往上拉）就換過去讀；沒有下一篇時也會明講。
- **文章工具側欄** — 視窗夠寬時，好讀文章右邊列出 AID、推文統計、提到你的推文、推文最多的人與本篇圖片，點一則就捲過去。
- **文章導覽軸** — 好讀文章右緣一條細軸，標出推文開始、新推文、提到你的推文與圖片的位置，點或拖就捲過去。
- **開燈** — 一鍵讓黑底黑字藏起來的雷或答案以黃色發光顯示。
- **翻譯漫畫圖文並排** — 「圖片＋翻譯」結構的文章可切成左圖右文兩欄，翻譯跟著捲動。
- **圖文並排 AI 校正（實驗性，需 Chrome）** — 用 Chrome 裝置端 AI 把被空行切散的翻譯一起搬進右欄，文章不會上傳。

### 📜 文章列表與看板列表

- **首頁儀表板** — 主功能表上列出我的最愛（有新文章的會標出來，逛完看板回來自動更新）、最近去過的看板和新信提示，點一下就進看板。
- **最近讀過／稍後再讀** — 自動記下最近讀過的文章，右鍵或長按文章可以收進「稍後再讀」，首頁和指令面板點一下就開回那篇，讀到一半的接著上次讀到的地方。
- **看板分頁** — 文章列表上方一排最近去過的看板，點一下切過去並回到上次看到的地方，長按關掉。
- **寬螢幕雙欄閱讀** — 視窗夠寬時，讀文章會在左邊列出剛才的文章列表，點一篇就直接換過去讀。
- **文章列表好讀模式（實驗性）** — 列表翻頁零延遲、背景預讀，滑鼠單擊即開文；列表忙的時候點的文章，忙完會自動開。
- **看板列表平滑捲動（實驗性）** — 我的最愛與分類看板累積成一整段清單，用瀏覽器原生捲動瀏覽。
- **列表原生捲動** — 列表好讀模式的滾輪、觸控板、鍵盤翻頁都是平滑捲動，不再一格跳一頁。
- **操作完自動切回好讀** — 搜尋、標記等原生操作做完會自動回到好讀列表；單純移動游標的鍵全程不切原生。
- **右鍵「此篇以前已讀、以後未讀」** — 對任一篇按右鍵即可設定已讀界線，免手動 `v` → `W`。
- **設為全部已讀** — 文章列表右鍵（手機在工具列「更多」）把整個看板設為已讀；看板列表對某個看板右鍵／長按也能設為已讀。
- **右鍵時標出選中的文章** — 開右鍵選單時框出目標文章，不會作用到錯的那篇。
- **已讀文章低亮** — 已讀文章整列調暗，未讀的一眼就看得到；手機上未讀的 `+` 會放大，有新推文的 `~` 稍微調暗。
- **快速捲動把手** — 捲動文章列表時右緣出現把手，拖動時顯示編號、放開就跳過去，大看板一次往回翻很遠。
- **跳到第一篇未讀** — 在文章列表按 `F7`（手機在工具列「更多」）直接跳到最早一篇還沒讀的文章。
- **跳過進板畫面** — 進看板時自動略過進板畫面（含動畫），直接到文章列表。
- **重新整理** — 看板列表、文章列表、文章、首頁儀表板按 F5（手機用工具列或下拉）就重抓新文章與新推文，不會斷線，位置不跑掉。

### 🚫 黑名單與關注

- **帳號／標題黑名單** — 隱藏指定帳號的推文與發文，或過濾標題含關鍵字的文章。
- **右鍵快速加入** — 對作者、推文者帳號或標題按右鍵直接加入黑名單，不用開設定。
- **關注名單** — 關注的作者或標題關鍵字在文章列表標上色條，關注的人推文時帳號也會上色；一鍵「只看關注」收起其他文章。

### 🖼️ 圖片與影片

- **自動開圖／影片預覽** — 圖片與影片連結自動預覽（各大圖床、imgur 相簿、X、YouTube、Twitch、tenor GIF），點圖整篇一起放大。
- **圖片倍率可調** — 滑鼠移到圖上按 ＋／－，以 50%～400% 調整整篇圖片大小。
- **單張轉灰階／原生圖片右鍵** — 單張圖一鍵轉灰階；圖片右鍵改用瀏覽器選單，可另存、複製或以圖搜圖。
- **圖片載入代理** — imgur、X、catbox 的圖片經本專案代理轉發快取，大幅減少卡住，可逐站開關。

### 🔗 連結與跳文

- **自動修復斷掉的連結** — 被空白截斷、被推文切成兩則或被換行切斷的網址，自動接回成可點連結。
- **更聰明的自動連結** — 沒寫 `https://` 的網域、含中文的網址、PTT 新版 `[文字](網址)` 超連結都能點；可選用裝置端 AI 複核減少誤判。
- **@帳號連到 X** — 內文與推文的 `@帳號` 自動連到 X（Twitter）。
- **Steamgifts 代碼連結** — Steam 板抽獎文的 giveaway 代碼自動變成連結。
- **文章代碼（AID）一鍵跳文** — 點 `#文章代碼` 直接跳到該篇，沒寫看板時可選本版或指定看板；之後按「← 返回」或 `F9` 回到原文原位置。
- **文章分享連結（deep link）** — 按 `F2` 複製本篇連結，別人點開就自動跳到該篇；網址列也會跟著目前文章變動。從列表點進來也能按「← 返回」回去。
- **右鍵複製文章代碼／分享連結** — 對任何文章代碼或 ptt.cc 文章網址按右鍵即可複製，選單會先顯示實際複製的內容。
- **連結沿用既有分頁** — 點外部連結時交給已登入的 PTT 分頁開啟，並以標題閃爍與系統通知提示你。

### 💬 推文、發文與搜尋

- **長推文一鍵發送** — 按 `X` 一次打完整段，自動依上限分段、遇到冷卻自動等待後依序推出，送完把剛推的那幾則亮一下；草稿關掉也不會不見，送到一半失敗可以只送剩下的。
- **底部推文列** — 好讀文章最下面一條推文輸入列，選推／噓／→、打完按 Enter 就推出去，打字時顯示還剩幾個字或會分成幾則；長按推文可直接回覆。
- **編輯器輸入框** — 發文、回文、寄信時跳出一般文字框，用手機鍵盤或輸入法打字，按「插入」整段送進編輯器。
- **拖曳貼圖上傳** — 把圖拖進視窗或貼上截圖，自動上傳到 [urusai](https://urusai.cc/) 圖床並把網址填進推文或文章。
- **搜尋彈窗** — 搜標題／作者／推文數／看板改用彈窗，按 ↑↓ 叫回之前搜過的關鍵字；看板名稱比照 PTT 邊打邊提示、打不進不存在的看板。
- **搜尋狀態列** — 停在搜尋結果時右上角顯示目前的搜尋條件，一鍵回完整列表或再加條件。
- **水球收件匣** — 這次連線收到的水球、系統廣播和新信提示留在右上角的鈴鐺裡，漏看了也找得回來，點任何一則的「回覆」直接回給那個人。
- **快速搜尋** — 選取文字後右鍵（手機長按字詞），直接用 Google、pixiv 或自訂的網站搜尋。

### 🖱️ 滑鼠與鍵盤

- **指令面板** — 按 F4 叫出一個輸入框，先列出最近的看板和我的最愛，打板名進板、貼文章網址開文、打關鍵字搜尋，或直接執行重新整理、跳到未讀等功能。
- **滑鼠操作重新設計** — 滑鼠設定集中一頁、可一鍵全關；點畫面最左邊回上一層，列表只在可點範圍內開文（範圍可自訂）。
- **邊緣點擊翻頁** — 找回 term.ptt.cc 原版的上下頁點擊區域，好讀模式下改為捲動。
- **功能鍵提示可直接點** — 畫面上的 `[←]離開`、`(X)推文` 等提示變成按鈕，點了等於按該鍵。
- **「按任意鍵繼續」點一下就關** — 進板畫面、訊息橫幅這類等你按鍵的畫面，點空白處即可關閉。
- **瀏覽器「上一頁」＝退出文章** — 觸控板左滑、滑鼠側鍵、`Alt+←` 改成回上一層，不會離開網站。
- **Alt（Mac 為 Option）＝ PTT 的 Ctrl** — 被系統或瀏覽器攔走的 Ctrl 組合，改按 Alt 就送得出去。
- **把滑鼠交給 PTT（預設關閉）** — 支援 PTT 的終端機滑鼠協定，點擊與滾輪直接回報給主機。
- **說明選單好讀** — 按 `h` 的操作說明一次列出全部指令，點一下就執行；手機從工具列「更多」打開，改成好點的底部選單。

### 🎨 外觀

- **暗色／淺色主題** — 介面採用現代化元件，預設暗色，可切淺色或跟隨系統。
- **游標列標示** — 游標所在列整列提亮，也可改用或並用自選顏色的底色。
- **游標不重複** — PTT 已畫出 `>` 游標的畫面，不再另外顯示閃爍游標。
- **上班模式** — 把 BBS 的高彩度配色換成低調暗灰色，只在本機生效。
- **提示音** — PTT 要求「嗶」一聲時播放短促提示音。
- **狀態提示可關閉** — 一般提示可以關掉；錯誤提示永遠顯示並改成紅底。

### 🔌 連線與登入

- **自動登入／2FA 自動填入** — 帳密交給瀏覽器密碼管理員保管，開網頁自動登入，也能自動填兩階段驗證碼。
- **內建 Proxy 連線** — 免裝擴充套件也能連上 PTT（見下方指南）。
- **連線失敗診斷** — 連不上時自動判斷是 Origin 設定問題還是 PTT 本身連不上，並可一鍵改用 Proxy 重連。
- **連線保持與斷線偵測** — 閒置時自動送連線保持封包，連線斷掉會立即提示重連。
- **斷線重連回到原處** — 重新連線登入後，自動回到斷線前讀的那篇文章與位置，或原本看的文章列表；Android App 在背景被系統回收後也一樣。
- **開站回到上次的地方** — 關掉分頁或被手機回收後再打開，登入後自動回到上次讀的文章或列表，出發前可以取消。
- **UTF-8 連線（實驗性）** — 可改用 UTF-8 與 PTT 連線，Big5 以外的字（如韓文、簡體字）照原字收送與顯示；預設仍為 Big5。

### 📱 手機與 App

- **手機版面（Android Chrome）** — 畫面自動塞滿螢幕，有 App 式標題列（點一下捲回頂端）與底部導覽列，列表、信箱與推文改成好點的卡片，長按推文就能整則複製，字級可另外調整。
- **Android App** — 切到背景也不斷線、收到水球跳系統通知，LINE、Telegram 裡的 PTT 文章連結直接在 App 開啟；APK 在 [GitHub Releases](../../releases)。
- **一鍵登出並關閉 App** — 登出時跳出全螢幕確認，可選只登出，或在 Android App 登出完直接關掉 App。

### ⚙️ 設定

- **偏好設定雲端同步** — 用 Google 登入後設定跨裝置同步，PTT 密碼絕不上傳。
- **設定匯出／匯入** — 設定存成 JSON 檔備份還原，不含帳密。
- **設定搜尋** — 設定頁左上角的搜尋框，中英文關鍵字都找得到。
- **快捷鍵一覽** — 設定頁「快捷鍵」分頁列出本站自己加的按鍵，跟著你目前的設定走。
- **更新後的新功能小卡** — 換新版後第一次回到主功能表時，右下角一張小卡列出這次多了哪些功能。
- **安全模式：全部用原生** — PTT 改版、畫面怪怪的時候一鍵把所有改寫畫面或代按鍵的功能暫停，關掉就恢復原本設定。
- **右鍵選單精簡** — 輸入小幫手、Live 文小幫手預設隱藏，需要時再開。
- **Debug 錄製模式** — 錄下連線資料回報難重現的 bug，也能在背景一直保留最近 3 分鐘、出事後再存檔。下載前自動遮蔽帳密與 IP。
- **AI agent 操作（實驗性）** — AI agent 可透過 Chrome DevTools Protocol 或 WebMCP 翻閱看板文章列表、讀取整篇文章與推文（含置底文）。

# 🛠️ PTT 三方網頁版連線修復指南

PTT 只接受來自官方網站 (`https://term.ptt.cc`) 的連線，所以第三方網頁版需要讓瀏覽器「假裝」從官方網站連線。以下兩種方法擇一即可。

## 🌟 方法一：安裝擴充套件（強烈推薦，最穩定！）

1. 安裝 [Requestly 套件](https://chromewebstore.google.com/detail/requestly-intercept-modif/mdnleldcmiljblolnjhpnblkcekpdkpa) 並登入。
2. 點 👉 **[匯入 PTT 連線設定](https://app.requestly.io/rules#sharedList/63df8d2912c644ae9c698383485d84bb-ptt)**，按右上角「**Import to my rules**」。
3. 重新開啟本站即可登入。

> 原理：連到 `wss://ws.ptt.cc/bbs` 時，把 Origin 改成官方的 `https://term.ptt.cc`，不動其他東西。

## ⚡ 方法二：使用內建 Proxy（免安裝擴充）

畫面按右鍵 →「**偏好設定**」→「**連線**」→ 勾選「**透過 proxy 連線**」，然後**重新整理網頁**。

- 「Proxy 位址」留空即使用內建的公開代理；也可填自己的（網址或 `wsstelnet://主機/路徑`）。
- 連線失敗時若判斷是 Origin 問題，提示框會直接問你要不要改用 Proxy，按「是」即可，不必重新整理。
- 經代理連線會比直連稍慢一點，屬正常現象。

# 🔗 讓 PTT 文章網址直接在本站開啟

裝好這條規則後，點到 `https://www.ptt.cc/bbs/看板/M.xxx.A.xxx.html` 這種官方文章網址，會自動改在本站開啟並跳到那篇文章（已有登入好的分頁就交給它開）。

1. 安裝 [Requestly 套件](https://chromewebstore.google.com/detail/requestly-intercept-modif/mdnleldcmiljblolnjhpnblkcekpdkpa)（與方法一相同，已裝過就跳過）。
2. 點 👉 **[匯入 PTT 文章網址跳轉設定](https://app.requestly.io/rules#sharedList/1879e51729bb474c8011b0d98216927e-ptt-deep-link)**，按「**Import to my rules**」。

> 原理：只認文章網址，把 `https://www.ptt.cc/bbs/<看板/檔名>` 改寫成 `https://abccbaandy.github.io/PttChrome/#<看板/檔名>`，再由本站的文章分享連結功能跳轉。自架站台請把目標網址換成自己的；想看官方網頁版時把這條規則關掉即可。

# 🔐 自動登入的密碼保存

在「偏好設定 → 自動登入」勾選「開啟網頁時自動登入」並填入帳密（與 2FA 密鑰，可留空）。

- 密碼交給**瀏覽器的密碼管理員**保管：第一次瀏覽器問「是否儲存密碼？」請按**儲存**；設定頁欄位空白代表已交給密碼管理員，不是沒存到。
- **Chrome** 支援最完整；**Edge** 目前讀不回密碼，自動登入可能失效；不支援密碼管理員的瀏覽器會以明文存在本機，請只在個人裝置使用。
- 2FA 密鑰與密碼存在同一處，等於放棄「密碼管理員被攻破」時的第二道保護；在意的話留空手動輸入驗證碼。
- PTT 密碼與 2FA 密鑰**絕不上傳雲端**，開啟雲端同步也一樣。
